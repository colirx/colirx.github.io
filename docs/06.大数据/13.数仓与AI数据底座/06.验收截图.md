## 1. DolphinScheduler

集群模式：PostgreSQL 元数据 + 独立 ZooKeeper + master/worker/api/alert。

![DolphinScheduler 集群实例](./images/2026-10-18-08-30-01.png)

![DolphinScheduler 工作流实例](./images/2026-10-18-08-30-02.png)

工作流包含 5 个任务：

- `t1`：Shell 检查 Flink CDC 作业；
- `batch_doris`：SQL 查 PostgreSQL；
- `spark-batch-job`：K8S 任务提交 PySpark 批量；
- `flink-k8s-list`：Flink CLI 查作业；
- `flink-k8s-cdc`：`sql-client` 提交 MySQL CDC → Kafka。
