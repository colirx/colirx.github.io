## 4. 已知边界

1. **Flink slot 只有 4 个**：3 个 CDC 会占满，批作业排队；
2. **OpenLineage 是桥接映射**：`ol-bridge` 硬编码 dataset → OM 表实体；
3. **OM 原生 S3/Iceberg dataset 解析未打通**；
4. **SHS 只扫新事件目录**，旧事件不会自动出现；
5. **单点**：Doris 1FE/1BE、Flink 1JM、DS 1master/1worker、OM/SHS 单副本；
6. **安全**：HTTP + 默认密码，端口未全部收敛；
7. **未做**：备份恢复、HA 演练、压测、TLS/SSO。

## 5. 结论

**功能验证通过，测试环境可以释放。**  
以上数字只代表 3 节点、1M 行、单副本测试环境，不等同于生产验收。

生产化前先看 [边界、风险与后续](05.待办与风险.md) 的检查清单。
