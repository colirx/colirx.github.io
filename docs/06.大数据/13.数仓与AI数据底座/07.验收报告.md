## 5. 已知边界与问题

1. **Flink slot 只有 4 个**：3 个 CDC 会占满，批作业需排队；生产建议扩 TM 或拆流/批集群。
2. **OL bridge 是硬编码映射**：`pg_orders_uncompressed`、`pg_orders_summary` 到 OM 实体 ID；生产需配置化。
3. **OM 原生 S3/Iceberg dataset 映射未打通**：当前依赖 bridge。
4. **SHS 旧事件**在 `warehouse/lake`，新 SHS 只扫 `warehouse/spark-events`。
5. **单点**：Doris 1FE/1BE、Flink 1JM、DS 1master/1worker、OM/SHS 单副本。
6. **安全**：UI 为 HTTP + 默认密码；Harbor/SHS 端口未放安全组。
7. **未做**：备份恢复、压测、HA 演练、TLS/SSO。
