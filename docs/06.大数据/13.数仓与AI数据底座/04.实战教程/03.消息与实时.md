# 03. 消息与实时

> 目标：MySQL/PostgreSQL 的变更能通过 Flink 写入 Kafka。  
> 本页所有资源都在 `data` namespace。

## 1. Kafka 3 broker（KRaft）

### 1.1 完整 manifest

保存为 `30-kafka.yaml`：

```yaml
apiVersion: v1
kind: Service
metadata:
  name: kafka-headless
  namespace: data
spec:
  clusterIP: None
  publishNotReadyAddresses: true
  selector:
    app: kafka
  ports:
    - name: plaintext
      port: 9092
    - name: controller
      port: 9093
---
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: kafka
  namespace: data
spec:
  serviceName: kafka-headless
  replicas: 3
  podManagementPolicy: Parallel
  selector:
    matchLabels:
      app: kafka
  template:
    metadata:
      labels:
        app: kafka
    spec:
      affinity:
        podAntiAffinity:
          requiredDuringSchedulingIgnoredDuringExecution:
            - labelSelector:
                matchLabels:
                  app: kafka
              topologyKey: kubernetes.io/hostname
      containers:
        - name: kafka
          image: docker.io/apache/kafka:3.9.0
          imagePullPolicy: IfNotPresent
          securityContext:
            runAsUser: 0
          command: ["bash", "-c"]
          args:
            - |
              set -e
              NODE_ID=${HOSTNAME##*-}
              printf '%s\n' \
                "process.roles=broker,controller" \
                "node.id=${NODE_ID}" \
                "controller.quorum.voters=0@kafka-0.kafka-headless.data.svc.cluster.local:9093,1@kafka-1.kafka-headless.data.svc.cluster.local:9093,2@kafka-2.kafka-headless.data.svc.cluster.local:9093" \
                "listeners=PLAINTEXT://0.0.0.0:9092,CONTROLLER://${POD_IP}:9093" \
                "advertised.listeners=PLAINTEXT://${POD_IP}:9092" \
                "controller.listener.names=CONTROLLER" \
                "listener.security.protocol.map=CONTROLLER:PLAINTEXT,PLAINTEXT:PLAINTEXT" \
                "inter.broker.listener.name=PLAINTEXT" \
                "log.dirs=/var/lib/kafka/data" \
                "num.partitions=3" \
                "offsets.topic.replication.factor=3" \
                "transaction.state.log.replication.factor=3" \
                "transaction.state.log.min.isr=2" \
                > /tmp/server.properties
              mkdir -p /var/lib/kafka/data
              if [ ! -f /var/lib/kafka/data/meta.properties ]; then
                /opt/kafka/bin/kafka-storage.sh format -t "$CLUSTER_ID" -c /tmp/server.properties
              fi
              exec /opt/kafka/bin/kafka-server-start.sh /tmp/server.properties
          ports:
            - containerPort: 9092
              name: plaintext
            - containerPort: 9093
              name: controller
          env:
            - name: CLUSTER_ID
              value: "MkU3OEVBNTcwNTJENDM2Qk"
            - name: POD_IP
              valueFrom:
                fieldRef:
                  fieldPath: status.podIP
          volumeMounts:
            - name: data
              mountPath: /var/lib/kafka/data
  volumeClaimTemplates:
    - metadata:
        name: data
      spec:
        accessModes: ["ReadWriteOnce"]
        storageClassName: local-path
        resources:
          requests:
            storage: 20Gi
```

关键点：

- `CONTROLLER` 和 `advertised.listeners` 都用 **Pod IP**，不能用 `0.0.0.0`；
- `CLUSTER_ID` 三台必须一致，可用 `kafka-storage random-uuid` 生成后写死；
- 反亲和确保 3 broker 分散到 3 台。

### 1.2 部署与验证

```bash
kubectl apply -f 30-kafka.yaml
kubectl -n data get pods -l app=kafka -o wide
```

预期三个 broker 分别在 node1/2/3，Running。

建 topic：

```bash
kubectl -n data exec kafka-0 -- /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server kafka-0.kafka-headless.data.svc.cluster.local:9092 \
  --create --topic cdc.orders --partitions 3 --replication-factor 3
```

验证：

```bash
kubectl -n data exec kafka-0 -- /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server kafka-0.kafka-headless.data.svc.cluster.local:9092 \
  --describe --topic cdc.orders
```

预期 `PartitionCount: 3`，每个 partition 的 `Isr` 有 3 个 broker。

## 2. MySQL（CDC 源）

### 2.1 完整 manifest

保存为 `20-mysql.yaml`，替换密码：

```yaml
apiVersion: v1
kind: Secret
metadata:
  name: mysql-secret
  namespace: data
type: Opaque
stringData:
  root-password: "<MYSQL_PASS>"
---
apiVersion: v1
kind: ConfigMap
metadata:
  name: mysql-cnf
  namespace: data
data:
  my.cnf: |
    [mysqld]
    server-id=1
    log-bin=mysql-bin
    binlog-format=ROW
    binlog-row-image=FULL
    gtid-mode=ON
    enforce-gtid-consistency=ON
---
apiVersion: v1
kind: ConfigMap
metadata:
  name: mysql-init
  namespace: data
data:
  init.sql: |
    CREATE DATABASE IF NOT EXISTS demo;
    CREATE TABLE IF NOT EXISTS demo.orders (
      id BIGINT PRIMARY KEY,
      user_id BIGINT,
      amount DECIMAL(10,2),
      status VARCHAR(20),
      updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
    );
    INSERT INTO demo.orders (id, user_id, amount, status) VALUES
      (1, 1001, 99.90, 'NEW'),
      (2, 1002, 199.00, 'PAID')
    ON DUPLICATE KEY UPDATE amount=VALUES(amount);
    CREATE USER IF NOT EXISTS 'flink'@'%' IDENTIFIED BY '<MYSQL_PASS>';
    GRANT SELECT, REPLICATION SLAVE, REPLICATION CLIENT ON *.* TO 'flink'@'%';
    FLUSH PRIVILEGES;
---
apiVersion: v1
kind: Service
metadata:
  name: mysql
  namespace: data
spec:
  selector:
    app: mysql
  ports:
    - name: mysql
      port: 3306
      targetPort: 3306
---
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: mysql
  namespace: data
spec:
  serviceName: mysql
  replicas: 1
  selector:
    matchLabels:
      app: mysql
  template:
    metadata:
      labels:
        app: mysql
    spec:
      securityContext:
        fsGroup: 999
      containers:
        - name: mysql
          image: docker.io/library/mysql:8.0
          imagePullPolicy: IfNotPresent
          env:
            - name: MYSQL_ROOT_PASSWORD
              valueFrom:
                secretKeyRef:
                  name: mysql-secret
                  key: root-password
          ports:
            - containerPort: 3306
              name: mysql
          volumeMounts:
            - name: data
              mountPath: /var/lib/mysql
            - name: cnf
              mountPath: /etc/mysql/conf.d
            - name: init
              mountPath: /docker-entrypoint-initdb.d
      volumes:
        - name: cnf
          configMap:
            name: mysql-cnf
        - name: init
          configMap:
            name: mysql-init
  volumeClaimTemplates:
    - metadata:
        name: data
      spec:
        accessModes: ["ReadWriteOnce"]
        storageClassName: local-path
        resources:
          requests:
            storage: 10Gi
```

## 3. PostgreSQL CDC 配置

`wal_level` 必须为 `logical`：

```bash
kubectl -n data exec postgres-0 -- psql -U postgres -c \
  "ALTER SYSTEM SET wal_level='logical';"
kubectl -n data exec postgres-0 -- psql -U postgres -c \
  "ALTER SYSTEM SET max_replication_slots=10;"
kubectl -n data exec postgres-0 -- psql -U postgres -c \
  "ALTER SYSTEM SET max_wal_senders=10;"
kubectl -n data rollout restart statefulset/postgres
```

验证：

```bash
kubectl -n data exec postgres-0 -- psql -U postgres -c \
  "SHOW wal_level; SHOW max_replication_slots;"
```

## 5. CDC SQL

### 5.1 MySQL → Kafka

```sql
SET 'execution.checkpointing.interval' = '10s';

CREATE TABLE mysql_orders (
  id BIGINT,
  user_id BIGINT,
  amount DECIMAL(10,2),
  status STRING,
  updated_at TIMESTAMP(3),
  PRIMARY KEY (id) NOT ENFORCED
) WITH (
  'connector' = 'mysql-cdc',
  'hostname' = 'mysql.data.svc.cluster.local',
  'port' = '3306',
  'username' = 'flink',
  'password' = '<MYSQL_PASS>',
  'database-name' = 'demo',
  'table-name' = 'orders',
  'server-id' = '5400-5404',
  'scan.incremental.snapshot.enabled' = 'true'
);

CREATE TABLE kafka_orders (
  id BIGINT,
  user_id BIGINT,
  amount DECIMAL(10,2),
  status STRING,
  updated_at TIMESTAMP(3),
  PRIMARY KEY (id) NOT ENFORCED
) WITH (
  'connector' = 'upsert-kafka',
  'topic' = 'cdc.orders',
  'properties.bootstrap.servers' = 'kafka-headless.data.svc.cluster.local:9092',
  'key.format' = 'json',
  'value.format' = 'json'
);

INSERT INTO kafka_orders SELECT * FROM mysql_orders;
```

提交：

```bash
kubectl -n data exec deploy/flink-jobmanager -- \
  /opt/flink/bin/sql-client.sh -f /opt/sql/mysql2kafka.sql
```

> SQL 文件可以通过 ConfigMap 挂载到 `/opt/sql`，也可以在镜像里内置。

### 5.2 PostgreSQL → Kafka

```sql
CREATE TABLE pg_orders (
  id BIGINT,
  user_id BIGINT,
  amount DECIMAL(10,2),
  status STRING,
  updated_at TIMESTAMP(3),
  PRIMARY KEY (id) NOT ENFORCED
) WITH (
  'connector' = 'postgres-cdc',
  'hostname' = 'postgres.data.svc.cluster.local',
  'port' = '5432',
  'username' = 'flink_pg',
  'password' = '<PG_PASS>',
  'database-name' = 'demo',
  'schema-name' = 'public',
  'table-name' = 'pg_orders',
  'slot.name' = 'flink_pg_slot',
  'decoding.plugin.name' = 'pgoutput'
);

CREATE TABLE kafka_pg (
  id BIGINT,
  user_id BIGINT,
  amount DECIMAL(10,2),
  status STRING,
  updated_at TIMESTAMP(3),
  PRIMARY KEY (id) NOT ENFORCED
) WITH (
  'connector' = 'upsert-kafka',
  'topic' = 'pg.cdc.orders',
  'properties.bootstrap.servers' = 'kafka-headless.data.svc.cluster.local:9092',
  'key.format' = 'json',
  'value.format' = 'json'
);

INSERT INTO kafka_pg SELECT * FROM pg_orders;
```

### 5.3 验证

```bash

  --bootstrap-server kafka-0.kafka-headless.data.svc.cluster.local:9092 \
  --topic cdc.orders --from-beginning --max-messages 5
```

Flink UI 或 REST 验证作业 RUNNING：

