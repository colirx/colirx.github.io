# 02. 存储与元数据

> 目标：有可用的本地存储、PostgreSQL 和 S3，Iceberg 能建库建表。  
> 所有命令默认在 node1 执行。

## 1. 创建 namespace

```bash
kubectl create namespace data --dry-run=client -o yaml | kubectl apply -f -
kubectl create namespace storage --dry-run=client -o yaml | kubectl apply -f -
```

## 2. local-path

```bash
kubectl apply -f https://raw.githubusercontent.com/rancher/local-path-provisioner/v0.0.30/deploy/local-path-storage.yaml
```

把默认目录改到 `/data/local-path`：

```bash
kubectl -n local-path-storage get configmap local-path-config -o yaml > /tmp/local-path-config.yaml
```

编辑 `config.json`，把 `paths` 改为：

```json
{
  "nodePathMap": [
    {
      "node": "DEFAULT_PATH_FOR_NON_LISTED_NODES",
      "paths": ["/data/local-path"]
    }
  ]
}
```

应用并设默认 StorageClass：

```bash
kubectl apply -f /tmp/local-path-config.yaml
kubectl patch storageclass local-path \
  -p '{"metadata":{"annotations":{"storageclass.kubernetes.io/is-default-class":"true"}}}'
kubectl get storageclass
```

验证 PVC：

```bash
cat <<'EOF' | kubectl apply -f -
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: pvc-test
  namespace: data
spec:
  accessModes: ["ReadWriteOnce"]
  resources:
    requests:
      storage: 1Gi
EOF

kubectl -n data get pvc pvc-test
kubectl -n data delete pvc pvc-test
```

预期 `Bound`。

## 3. PostgreSQL

### 3.1 完整 manifest

保存为 `10-postgres.yaml`，把密码换成自己的：

```yaml
apiVersion: v1
kind: Secret
metadata:
  name: postgres-secret
  namespace: data
type: Opaque
stringData:
  password: "<PG_PASS>"
---
apiVersion: v1
kind: ConfigMap
metadata:
  name: postgres-init
  namespace: data
data:
  init.sql: |
    CREATE USER polaris WITH PASSWORD '<PG_PASS>';
    CREATE DATABASE polaris OWNER polaris;
    CREATE DATABASE iceberg OWNER polaris;
    CREATE DATABASE openmetadata OWNER polaris;
    CREATE DATABASE dolphinscheduler OWNER polaris;
---
apiVersion: v1
kind: Service
metadata:
  name: postgres
  namespace: data
spec:
  selector:
    app: postgres
  ports:
    - name: pg
      port: 5432
      targetPort: 5432
---
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: postgres
  namespace: data
spec:
  serviceName: postgres
  replicas: 1
  selector:
    matchLabels:
      app: postgres
  template:
    metadata:
      labels:
        app: postgres
    spec:
      containers:
        - name: postgres
          image: docker.io/library/postgres:16-alpine
          imagePullPolicy: IfNotPresent
          ports:
            - containerPort: 5432
          env:
            - name: POSTGRES_PASSWORD
              valueFrom:
                secretKeyRef:
                  name: postgres-secret
                  key: password
            - name: PGDATA
              value: /var/lib/postgresql/data/pgdata
          resources:
            requests:
              cpu: 500m
              memory: 1Gi
            limits:
              cpu: "2"
              memory: 4Gi
          volumeMounts:
            - name: data
              mountPath: /var/lib/postgresql/data
            - name: init
              mountPath: /docker-entrypoint-initdb.d
      volumes:
        - name: init
          configMap:
            name: postgres-init
  volumeClaimTemplates:
    - metadata:
        name: data
      spec:
        accessModes: ["ReadWriteOnce"]
        storageClassName: local-path
        resources:
          requests:
            storage: 10Gi
```

应用：

```bash
kubectl apply -f 10-postgres.yaml
kubectl -n data get pods -l app=postgres
kubectl -n data logs postgres-0 --tail=20
```

预期 `postgres-0 1/1 Running`。

### 3.2 验证

```bash
kubectl -n data exec -it postgres-0 -- psql -U postgres -c '\l'
```

应该看到：

```text
polaris
iceberg
openmetadata
dolphinscheduler
```

建 `demo` 库和 CDC 用户：

```bash
kubectl -n data exec -i postgres-0 -- psql -U postgres <<'SQL'
CREATE DATABASE demo;
CREATE USER flink_pg WITH REPLICATION LOGIN PASSWORD '<PG_PASS>';
GRANT ALL PRIVILEGES ON DATABASE demo TO flink_pg;
SQL
```

进入 demo 建表：

```bash
kubectl -n data exec -i postgres-0 -- psql -U postgres -d demo <<'SQL'
CREATE TABLE IF NOT EXISTS pg_orders (
  id BIGINT PRIMARY KEY,
  user_id BIGINT,
  amount DECIMAL(10,2),
  status VARCHAR(20),
  updated_at TIMESTAMP DEFAULT now()
);
GRANT SELECT ON pg_orders TO flink_pg;
SQL
```

## 4. SeaweedFS S3

### 4.1 values

安装 Helm repo：

```bash
helm repo add seaweedfs https://seaweedfs.github.io/seaweedfs/helm
helm repo update
```

保存 `values-seaweedfs.yaml`：

```yaml
master:
  replicas: 3
  defaultReplication: "001"
  data:
    type: persistentVolumeClaim
    size: 5Gi
    storageClass: local-path

volume:
  replicas: 3
  dataDirs:
    - name: data1
      type: persistentVolumeClaim
      size: 50Gi
      storageClass: local-path
      maxVolumes: 0

filer:
  replicas: 2
  data:
    type: persistentVolumeClaim
    size: 10Gi
    storageClass: local-path

s3:
  enabled: true
  replicas: 2
  enableAuth: true
  createBuckets:
    - name: warehouse
```

### 4.2 安装

```bash
helm upgrade --install seaweedfs seaweedfs/seaweedfs \
  -n storage --create-namespace \
  -f values-seaweedfs.yaml
```

验证：

```bash
kubectl -n storage get pods
kubectl -n storage get svc
```

预期：

```text
seaweedfs-master-0/1/2   Running
seaweedfs-volume-0/1/2   Running
seaweedfs-filer-0/1      Running
seaweedfs-s3-...         Running
```

### 4.3 取 S3 凭证

```bash
kubectl -n storage get secret seaweedfs-s3-secret -o jsonpath='{.data}' ; echo
```

解码：

```bash
kubectl -n storage get secret seaweedfs-s3-secret \
  -o jsonpath='{.data.admin_access_key_id}' | base64 -d; echo
kubectl -n storage get secret seaweedfs-s3-secret \
  -o jsonpath='{.data.admin_secret_access_key}' | base64 -d; echo
```

保存到变量：

```bash
export S3_ENDPOINT=http://seaweedfs-s3.storage.svc.cluster.local:8333
export S3_AK=<access-key>
export S3_SK=<secret-key>
```

验证 S3：

```bash
kubectl -n data run s3check --rm -it --image=amazon/aws-cli:latest --command -- \
  aws --endpoint-url $S3_ENDPOINT s3 ls
```

预期能看到 `warehouse` bucket。

## 5. Iceberg JDBC catalog

测试环境不依赖 Polaris，直接用 JDBC catalog。

### 5.1 元数据库

`iceberg` 库已在 PostgreSQL init 中创建。

### 5.2 Spark 配置

后续 Spark 任务统一带：

```text
spark.sql.catalog.lake=org.apache.iceberg.spark.SparkCatalog
spark.sql.catalog.lake.type=jdbc
spark.sql.catalog.lake.uri=jdbc:postgresql://postgres.data:5432/iceberg
spark.sql.catalog.lake.jdbc.user=polaris
spark.sql.catalog.lake.jdbc.password=<PG_PASS>
spark.sql.catalog.lake.warehouse=s3://warehouse/lake
spark.sql.catalog.lake.io-impl=org.apache.iceberg.aws.s3.S3FileIO
spark.sql.catalog.lake.s3.endpoint=http://seaweedfs-s3.storage:8333
spark.sql.catalog.lake.s3.path-style-access=true
spark.sql.catalog.lake.s3.access-key-id=<S3_AK>
spark.sql.catalog.lake.s3.secret-access-key=<S3_SK>
spark.sql.catalog.lake.client.region=us-east-1
```

### 5.3 验证

用 Spark 镜像启动一个临时 Pod：

```bash
kubectl -n data run spark-client --image=<REGISTRY>/spark:3.5.9-iceberg \
  --restart=Never --command -- sleep 3600
```

进入 Pod：

```bash
kubectl -n data exec -it spark-client -- bash
```

执行：

```bash
/opt/spark/bin/spark-sql \
  --conf spark.sql.catalog.lake=org.apache.iceberg.spark.SparkCatalog \
  --conf spark.sql.catalog.lake.type=jdbc \
  --conf spark.sql.catalog.lake.uri=jdbc:postgresql://postgres.data:5432/iceberg \
  --conf spark.sql.catalog.lake.jdbc.user=polaris \
  --conf spark.sql.catalog.lake.jdbc.password='<PG_PASS>' \
  --conf spark.sql.catalog.lake.warehouse=s3://warehouse/lake \
  --conf spark.sql.catalog.lake.io-impl=org.apache.iceberg.aws.s3.S3FileIO \
  --conf spark.sql.catalog.lake.s3.endpoint=http://seaweedfs-s3.storage:8333 \
  --conf spark.sql.catalog.lake.s3.path-style-access=true \
  --conf spark.sql.catalog.lake.s3.access-key-id='<S3_AK>' \
  --conf spark.sql.catalog.lake.s3.secret-access-key='<S3_SK>' \
  -e "CREATE NAMESPACE IF NOT EXISTS lake.ods;"
```

再建表：

```sql
CREATE TABLE IF NOT EXISTS lake.ods.orders (
  id BIGINT,
  amount DECIMAL(10,2)
) USING iceberg;

INSERT INTO lake.ods.orders VALUES (1, 10.00);
SELECT count(*) FROM lake.ods.orders;
```

预期 `1`。
