# 成果台账

> 回答那个问题："学习成果是不是要我自己加进来？" —— **是，而且这是整个仓库最重要的部分。**
> 计划、卡片、资源清单都是别人能给你的；**只有产物是你自己的**。招聘方看的是这一页。

## 登记规则

1. 每完成一个**可运行的产物**，就在下表补一行。不是完成一个里程碑才登记，是一个产物就登记一行。
2. 「可运行」是硬标准：别人 clone 下来能跑出同样结果，才算数。看完一门课不算产物。
3. 计划外自己做的探索也登记——那往往比计划内的更有说服力。
4. 里程碑收口时，在该行的「验证」栏填上验证标准的实际结果（数字，不是"通过"）。

## 为什么这一页比计划更重要

- 计划证明你**知道**该学什么；台账证明你**做出来了**。
- 面试时能被追问的是台账里的每一行，而不是 README 里的表格。
- 台账一旦连续几个月是空的，说明计划本身有问题——**该改计划，不该硬撑**。
