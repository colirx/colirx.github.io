_为什么语言模型评测里到处出现"困惑度"？它和交叉熵是什么关系？_

## 三个必须记住的等式

1. 交叉熵 = 熵 + KL 散度
2. 最小化交叉熵 ⇔ 最小化 KL 散度
3. 困惑度 = 交叉熵的指数

_每一条用一句自己的话展开。想不出来就回看西湖大学张岳那一集（19 分钟，看两遍）。_

## 直觉解释

- **熵**：不确定性有多大。抛硬币 vs 抛骰子，哪个熵高？
- **交叉熵**：用"我以为的分布"去编码"真实的分布"，平均要花多少代价
- **KL 散度**：我错了多少。它为什么不对称？
- **困惑度**：模型每一步平均在多少个候选之间犹豫
