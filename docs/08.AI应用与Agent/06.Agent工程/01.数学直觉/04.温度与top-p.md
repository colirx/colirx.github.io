## 它解决什么问题

_模型输出的不是一个词，而是一个概率分布。从分布里"选一个"的过程，就是采样。_
_temperature 和 top-p 改的是这个选择过程，不是模型本身。_

## 核心机制

- **logits → softmax → 概率分布**：这条链路上 temperature 插在哪里
- **temperature = 0.1 / 1.0 / 2.0**：分布形状分别变成什么样
- **top-p（核采样）**：先按概率从高到低累加，凑够 p 就把尾巴砍掉，再在剩下的里采样
- **top-k**：直接取前 k 个。它和 top-p 的区别是什么？各自什么时候更合适？

## 一个必须想清楚的问题

_为什么说 temperature 调低"更确定"？如果模型本来就很确信，调低还有效果吗？_
