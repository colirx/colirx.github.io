## 三个必须分清的层次

| 层次 | 含义 | 例子 |
|---|---|---|
| 位宽 | 一个数用多少 bit 表示 | fp32 / fp16 / bf16 / int8 / int4 |
| 有效位数 vs 动态范围 | 精度和范围是两件事，不能同时最大化 | bf16 范围大但精度低；fp16 反过来 |
| 量化粒度 | 整个张量共用一个缩放因子，还是每行/每组一个 | per-tensor / per-channel / group-wise |
