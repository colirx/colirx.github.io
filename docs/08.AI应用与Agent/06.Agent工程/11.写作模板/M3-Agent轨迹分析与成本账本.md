## 五、常见偷懒（自查是否犯）

- 只报告"能跑通"的那几个任务，不报告失败率——成功案例谁都能挑出来。
- 不算成本，说"反正本地跑不花钱"——token 和耗时就是钱，算不出来说明日志埋得不够。
- 没有最大步数兜底就宣称稳定——跑飞一次就可能烧掉一晚上的预算。
- 把"重试后成功"直接算成成功，不单列重试次数——重试率上升本身就是退化。
- token 账本只给总数不给分解——那正好回答不了"钱花在哪一步"。
