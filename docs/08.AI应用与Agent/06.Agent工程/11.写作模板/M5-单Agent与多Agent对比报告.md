## 四、验收清单（写完自查）

- [ ] 两种编排都在真实任务上端到端跑通，且共用 M3 的循环与工具层
- [ ] A/B 用的是同一任务集，成功判定口径完全一致
- [ ] 报告里既有均值也有标准差，没有任何只靠均值支撑的结论
- [ ] ≥1 个"拆了反而更差"的案例，并说清原因（不是"可能不划算"）
- [ ] 拆分判据是可复用清单，不含"视情况而定"这类空话

## 五、常见偷懒（自查是否犯）

- 只比均值不比方差——多 Agent 常常均值更高、方差也更大，不写方差等于藏了一半真相。
- 两种编排用了不同任务集——那不是 A/B，那是两份互不相干的报告。
- 因为"多 Agent 听起来更强"就先下结论，再挑数据支持它——预期必须写在实验之前。
- 成功判定口径对多 Agent 悄悄放宽（比如多给一次重试机会）——口径要锁死并写出来。
