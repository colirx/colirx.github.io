## 每篇笔记的填写规则

1. **一概念一文件**，文件名用「概念名.md」，不要用日期或 part 编号。
2. 文件头必须有 `> 选题意图：` 一行 —— 说不清这篇要解决什么，就先别写。
3. **必须有可运行代码或可视化**。抄的定义不算数。
4. 结论必须带数字或明确条件；"效果更好"这种话不写。
5. 写不动、没搞懂的部分，写进「待补」栏**然后继续**，不要卡在那里。

> 完整评审标准见 `agent-engineering-path/ops/knowledge-workflow.md`。
